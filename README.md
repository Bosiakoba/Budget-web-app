## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `https://bosiakoba.github.io`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://bosiakoba.github.io) to automatically optimize and load [Geist](https://bosiakoba.github.io), a new font family for Vercel.
